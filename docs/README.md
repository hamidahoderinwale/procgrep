# procgrep docs

The public-facing writeup, reference pages, and the figures plus data they
render from. Read this when you want to know what lives where under `docs/`.

- `index.html`: the interactive web essay. Generated, not hand-edited; built by
  `paper/build_paper.py`.
- `paper/`: essay and paper source: `paper/src/` (LaTeX + bib), `paper/data/`
  (the JSON each interactive figure reads), `paper/build_paper.py` (the builder).
- `figures/`: figure assets used by the essay: static PNGs plus interactive D3
  versions (`*.html` + their `*.json`), rendered through the shared
  `explorer/d3charts.js` module. Generated by `analysis/fig_*.py`.
- `explorer/`: a static, embeddable copy of the trace explorer.
- `assets/`: shared CSS and images for the hosted pages.
- `build/`: the ecosystem-map builder and its output (a self-contained
  `index.html`, generated, not served by Pages).
- `METRICS.md`, `STUDIES.md`: the measurement reference and worked case studies.

GitHub Pages serves the site from this directory; `index.html` is the landing
page.

## Regenerating figures

Plot outputs resolve to this checkout's `docs/figures/`, regardless of the working
directory. The patch-size, trajectory-length, and step/token-cost scripts read
from a sibling `bidirect-align-dev-traces` checkout by default. Set `BIDIRECT_ROOT`
to use a different location, for example:

```bash
BIDIRECT_ROOT=/path/to/bidirect-align-dev-traces python analysis/fig_regression_length.py
```

The paper cache reader accepts `--cache-dir /path/to/trajectory-cache`. These
external inputs are not bundled with procgrep.
